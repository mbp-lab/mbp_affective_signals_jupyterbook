# Welcome

Welcome to **Multimodal Behavior Processing: Affective Signals** for WiSe 2026/27 at Bielefeld University.

**Lecture:** Prof. Dr. Hanna Drimalla  
**Tutorials:** Rituja Pardhi

This course explores different modalities used in the multimodal analysis of human behaviour. The practical notebooks guide you through analysing facial behaviour, eye gaze, voice, breathing, and heart activity.

<details>
<summary><strong>How to use this book</strong></summary>

Begin with the [Setup](./setup.md) chapter before opening the practical notebooks. The website provides an organised reading version of the course material and lets you download the original notebooks. Run and complete the notebooks in the local Docker and Jupyter environment described in Setup, using your own recorded data.

</details>
